# Охлаждение в баре Omarchy

[English](README.md)

Вентиляторы и температуры на любом компе: температура процессора в баре с цветом по нагреву, в окне
все вентиляторы, которые видит ядро, температуры по группам и режим питания.

- **Вентиляторы**: всё, что отдаёт hwmon (hp-wmi, thinkpad, asus, dell, nct, it87, acpi_fan…). Если
  Linux не видит ни одного, так и пишет.
- **Температуры**: процессор (корпус и самое горячее ядро), видеокарта, SSD, плата. Видеокарта NVIDIA
  читается только при открытом окне и **не будится из сна**.
- **Режим**: Тихо / Баланс / Мощно через power-profiles-daemon, без root. Правый клик в баре
  переключает.

## Установка

```bash
omarchy plugin add https://github.com/ismoil77/omarchy-cooling --enable
```

## Удаление

```bash
omarchy plugin remove ismoil.fans
```
